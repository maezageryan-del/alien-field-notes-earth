## The entry

> Four stars. The locals smear cream on their skin so their own star won't burn them, then lie under it all afternoon on purpose. Would tan again.

144 characters, one line, no trailing newline.

## Why this line

A real tourist review needs a rating, a specific detail, and a closing
verdict — this one has all three. The detail is a single everyday ritual,
seen through a visitor's eyes: the locals treat their own star as both a
hazard to hide from and a pleasure to lie under. Nothing else in the line
competes with that one observation, and the punch lands in the last three
words.

## How it works

`main.py` writes the review above to `entry.txt` in the output directory
(`$MAKEFUN_OUTPUT_DIR`, default `/output`). A guard keeps the text inside
the bounty's 1–200 character gate and on a single line.

```sh
python3 main.py
```
